```
[중심 문서 (이 파일)]  ── 어떤 문서를 언제 읽는지 안내
        │
        ├─▶ [제품 소개서]      "무엇인가·왜 필요한가·중심 기능"  (개요, 비개발자)
        │
        └─▶ [상세 기능 소개서]  "각 기능이 무엇을·어떻게·어떤 통제"  (카테고리별, 실무)
```

- **상세 기능 소개서**는 *"그래서 각 기능이 정확히 뭘 해주는가"* 를 카테고리별로 파고듭니다.
- 둘 다 **캡처 자리를 주석**으로 표시해 두었습니다(`<!-- [캡처 …] … → docs/images/… -->`).

## 30초 핵심 (외우기용)

1. **정체성:** "보는 층"(Grafana)이 아니라 **"증적 층"** — 운영 신호 → 사람 판단 → 통제 증적.
2. **대표 기능:** 코드 스캔으로 **개인정보 처리흐름도 + 감사 PDF 자동 생성**.
3. **성격:** **정직한 증적** — 자동 사실 / AI 후보 / 사람 판단을 구분해 보여줌(부풀리지 않음).
4. **도입:** 기존 도구를 안 버리고 `.env` 설정만으로 **읽기 전용**으로 얹힘.

- 제품 소개서·상세 기능 소개서: 초안(캡처 이미지 삽입 필요 — 각 문서의 주석 참고).

- 제품은 **알파** 단계 — 검증 범위는 각 문서의 "정직하게 말하면" 절 참고.
